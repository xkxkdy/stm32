1.git add 需要上传的文件名(尽量只上传代码、照片、txt等，软件好像不行)

2.git commit -m "里面随便写，这主要是用来说明你此次提交时的备注"

3.git push origin main

如果上传不上去可以查看下面命令
$ git config --global -l
看是否显示下面内容
user.name=Mr.zhou
user.email=2029365440@qq.com
http.proxy=http://127.0.0.1:7890

不是的话git config --global http.proxy http://127.0.0.1:7890

如果将某一个文件内容改变想要上传跟新后的内容，而其他不改变
git status
如果显示的内容里有modified:   "git\344\270\212\344\274\240\346\226\271\345\274\217.txt"
不一定一模一样主要是有modified就行，也不用关心下方deleted
git add *
之后再git status发现modified:......就没有了，说明已经将更新的内容上传到了缓存区了
在执行下面这两步就可以将内容更新进去，并且不改变其它内容
2.git commit -m "里面随便写，这主要是用来说明你此次提交时的备注"
3.git push origin main
